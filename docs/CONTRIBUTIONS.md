# Contributions and Project Credits

## Project overview

**TreeMap-ITE** is a collaborative educational project that combines tree observations, interactive mapping, and environmental data visualization. The project brings together technical development, project coordination, and field observation work.

The project is associated with **Instituição Toledo de Ensino (ITE)**.

## Leonardo Ribeiro — Technical contributions

Leonardo is the **primary developer of the TreeMap-ITE web application** and, according to the current project workflow, the person responsible for editing and maintaining its code. His development work has covered most of the application's technical implementation, including:

- Implementing and improving the public-facing web interface and responsive layouts.
- Building and refining the interactive map and tree-observation presentation.
- Integrating observation data through the application's API-facing frontend code.
- Implementing or maintaining observation cards, filters, and project statistics.
- Working with tree measurement processing and environmental calculation features.
- Developing and maintaining features as project requirements evolve.
- Working with the application files and deployment environment on a remote server.

This is a **responsibility summary**, not a line-by-line claim that Leonardo independently conceived every feature or authored every external library, dataset, or dependency used by the project.

## Collaborative project work

The project coordinators guide and organize the initiative. The observation contributors are responsible for the observation work that provides the project with its tree records. Leonardo translates the project's functional needs into software and maintains the codebase.

The distinction is intentional: **software implementation is primarily Leonardo's responsibility**, while the project's direction and tree-observation work are collaborative efforts.

## Scope of this public repository

This repository is a curated source snapshot for documentation, educational review, and Leonardo's technical portfolio. It does **not** contain the complete production application.

The following components are intentionally not distributed:

- Protected PHP API implementation and private service configuration.
- Administrative panel and authentication-related implementation.
- Credentials, secrets, and other internal server configuration.
- Third-party service configurations, event photographs, and scientific reference data excluded from this snapshot.

For a working version of the application, visit the [TreeMap-ITE website](https://treemap.savi.tec.br/).
